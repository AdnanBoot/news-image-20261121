A deterministic Pillow (`PIL`) program that renders a one-image summary of the world news of **Saturday 21 November 2026** as a 1024×1024 broadsheet newspaper front page (`WORLD NEWS`).

## How to Run

Regenerate `entry.png` from `draw.py`:

```bash
python3 draw.py
```

Copy `entry.png` to the output directory (`MAKEFUN_OUTPUT_DIR`, defaulting to `/output`) and verify its SHA-256 checksum:

```bash
python3 main.py
```
